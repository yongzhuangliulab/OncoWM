# Downloaded Model Layout

[中文](README.md)

Place models downloaded from external sources under this directory. Weight files are ignored by Git; only this guide is tracked.

```text
pretrained_models/
├── medgemma-1.5-4b-it/
├── conch-v1.5/
├── titan/
├── bulkformer/
└── mjepa/
    └── <CANCER>_<ENDPOINT>/
        └── full_cohort/
            └── prognosis_full_final.pth.tar
```

Keep each third-party model's complete release structure. Do not copy only one weight file while omitting its `config.json`, tokenizer, or related assets.

Do not confuse:

- `pretrained_models/`: downloaded third-party models and published M-JEPA checkpoints;
- `outputs/train/`: checkpoints, splits, and logs generated by training in this repository.

## Whole-slide images

The model reads `pathology.pt`, not `.svs` files. An external preprocessing pipeline must first extract patch features and aggregate them into a patient-level embedding:

```text
SVS → CONCH patch features → TITAN embedding → pathology.pt
```

The complete SVS preprocessing pipeline is not included in this repository.
